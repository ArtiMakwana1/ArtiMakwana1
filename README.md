## 🚀 Featured projects

### [Agentic COVID-19 RAG Chatbot](https://github.com/ArtiMakwana1/covid_rag_chatbot)

An LLM agent (Llama 3.3 70B on Databricks) that decides, for each question, whether to search a FAISS index built from COVID-19 PDFs, look up Wikipedia, or answer directly. Answers come with page-level citations, the chat remembers earlier turns, and evaluation runs are tracked in MLflow.

`Databricks` `LangChain` `FAISS` `Sentence Transformers` `Llama 3.3 70B` `MLflow`

### [Intelligent News Classifier](https://github.com/ArtiMakwana1/intelligent-news-classifier) · [▶ Live demo](https://intelligent-news-classifier.streamlit.app/)

Sorts news articles into World, Sports, Business and Sci/Tech. A tuned TF-IDF + Linear SVM model trained on 120,000 AG News articles reaches **90.2% accuracy** on 7,600 held-out articles. A 4-person capstone project; my part was the preprocessing and training pipeline, the model tuning that produced the deployed model, and the error analysis.

`scikit-learn` `TF-IDF` `Linear SVM` `Streamlit`
